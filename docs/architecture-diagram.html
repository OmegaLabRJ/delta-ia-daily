3. Data & Persistence Layer — Supabase

🗄️ 3.1 Business & Customer Data

  • profiles — Professionals, stores, consumers
  • marketplace_items — Services, products & prices
  • client_profiles — Per-merchant client records
  • posts — Content & engagement metrics
  • content_calendar — AI-generated 30-day plans

📅 3.2 Real-Time Scheduling

  • appointments — Transactional & conflict-safe
  • schedules — Working days, breaks, slot duration
  • get_week_availability() — PostgreSQL RPC function
  • UNIQUE constraint — DB-level anti-double-booking
  • Transaction locking + real-time conflict detection
  • Automatic past-hour filtering for today

🧠 3.3 3-Layer Memory Architecture

  • Short-term: chat_messages — Session chat history (last 15-40 msgs)
  • Mid-term: ai_chat_sessions — Context with TTL auto-refresh (5min)
  • Long-term: professional_memory — Persistent business facts with confidence scoring & TTL expiry
  • Deduplication with 40-char fuzzy matching
  • Client preference accumulation (silent)

📊 3.4 Audit & Observability

  • ai_usage_logs — Every tool call, latency_ms, status
  • ai_action_feedbacks — User feedback on AI actions (edited/accepted/cancelled)
  • intent_feedback — Classifier error collection (closed-loop)
  • ai_chat_history — Full conversation audit trail
  • Token consumption tracking per session
  • 100% traceable — Every autonomous action auditable

🛡️ 3.5 Security & Trust

  • Edge Functions — API keys hidden server-side
  • JWT Auth — Supabase token validation
  • RLS Policies — Row-level security per user
  • Dual Rate Limiting — Server (20/min) + Client (2s cooldown)
  • Exponential Backoff — With jitter for Gemini 429s
  • History Size Guard — Max 100 messages per request
